# Netflix Movies & TV Shows - Exploratory Data Analysis (EDA)

An end-to-end data analytics project uncovering content patterns, platform growth trends, and geographic distributions across Netflix releases using Python.

## 📌 Project Overview
The objective of this project is to perform comprehensive Exploratory Data Analysis (EDA) on Netflix title records. By applying data cleaning, transformation, and exploratory visualizations, this project derives business-relevant insights regarding content acquisition strategies and international market expansion.

## 🔍 Key Insights & Analysis
* **Content Portfolio Distribution**: Analyzed the proportion between standalone feature films and multi-season TV shows to evaluate library depth.
* **Geographic Production Hubs**: Identified leading content-producing regions globally (US, India, UK) driving regional subscriber retention.
* **Year-over-Year Platform Growth**: Visualized catalog expansion patterns over time, identifying peak acquisition periods.
* **Data Sanitization & Preprocessing**: Managed missing values across production credits, cast metadata, and localized release metrics.

## 🛠️ Tech Stack & Tools
* **Language**: Python
* **Data Manipulation**: Pandas, NumPy
* **Data Visualization**: Matplotlib, Seaborn
* **Environment**: Jupyter Notebook / Google Colab
